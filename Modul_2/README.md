# Исследование лояльности пользователей Яндекс Афиши

## О проекте

Данный проект посвящён исследовательскому анализу данных (EDA) для выявления ключевых факторов, влияющих на удержание и повторные покупки пользователей на платформе Яндекс Афиша.

**Цель:** Определить, какие характеристики пользователей и их первого заказа связаны с вероятностью возврата на платформу, чтобы помочь отделу маркетинга в сегментации аудитории и оптимизации рекламных бюджетов.

## Ключевые результаты

В ходе анализа были проверены несколько продуктовых гипотез и сделаны следующие выводы:

1.  **Признаки первого заказа (жанр, устройство, регион, оператор) являются слабыми предикторами возврата.** Разница в доле возврата между сегментами незначительна (3-12 п.п.), и корреляционный анализ (phi_k) подтвердил почти полное отсутствие связи с общим числом заказов.
2.  **Среднее количество билетов в заказе — сильный и информативный признак.**
    *   Пользователи, покупающие в среднем **2–3 билета**, возвращаются чаще всего (**73.2%**).
    *   Пользователи, покупающие **5+ билетов**, имеют аномально низкую долю возврата (**18.8%**). Это связано с тем, что такие заказы часто делают корпоративные клиенты или «перекупщики», а не частные лица.
3.  **Регулярность покупок — ключевой фактор удержания.** Пользователи, совершающие заказы с короткими и стабильными интервалами (медиана ~8-9 дней), с гораздо большей вероятностью становятся постоянными клиентами (5+ заказов), чем те, у кого были длительные перерывы.
4.  **День недели первого заказа не влияет на вероятность возврата.** Разброс значений минимален и находится в пределах случайной вариации.

## Структура проекта

Ноутбук разделён на логические этапы:

1.  **Загрузка данных и знакомство с ними.** Подключение к базе данных, формирование итогового датасета с помощью SQL-запроса.
2.  **Предобработка данных.**
    *   Приведение выручки к единой валюте (рубли).
    *   Оптимизация типов данных.
    *   Анализ и обработка пропусков.
    *   Выявление и фильтрация аномалий (отрицательная выручка, аномально активные пользователи).
3.  **Создание профиля пользователя.** Агрегация данных на уровне пользователя для получения признаков, описывающих его поведение.
4.  **Исследовательский анализ данных (EDA).**
    *   Анализ распределения пользователей по признакам.
    *   Проверка продуктовых гипотез.
    *   Исследование поведения пользователей через показатели выручки и состава заказа.
    *   Анализ временных характеристик (день недели, лайфтайм, интервал между заказами).
    *   Корреляционный анализ (phi_k) для выявления наиболее значимых признаков.
5.  **Итоговые выводы.**

## Используемые технологии

*   **Python 3.13**
*   **Pandas** для обработки и анализа данных
*   **SQLAlchemy & Psycopg2** для подключения к базе данных
*   **Matplotlib & Seaborn** для визуализации данных
*   **Phik** для расчёта корреляции phi_k
*   **Jupyter Notebook** в качестве среды разработки
