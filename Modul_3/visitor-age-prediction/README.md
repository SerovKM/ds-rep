# Прогнозирование возрастной категории посетителей сайта

Учебный проект по многоклассовой классификации пользователей сайта «Йети». Цель — определить возрастную категорию пользователя по признакам, собранным из шести исходных таблиц.

[Открыть ноутбук с результатами](Model_for_predicting_the_age_of_website_visitors.ipynb)

## Подход и результаты

В ноутбуке формируются и отбираются признаки, сравниваются логистическая регрессия и SVC, подбираются гиперпараметры. Лучшей моделью стала **SVC с ядром RBF** (`C=3`, `gamma=0.05`).

- **Macro F1 на тестовой выборке — 0,8994** при целевом пороге 0,75.
- Для категории младше 18 лет полнота составила **0,92**.
- После сохранения и загрузки пайплайна предсказания совпали на всех 1 000 наблюдениях в отдельной проверке.

## Данные и окружение

Исходные таблицы в репозиторий не включены. Ноутбук читает их из `/datasets/` и при необходимости пробует загрузить их с учебного сервера. Графики, таблицы и метрики доступны в сохранённых выводах. Вспомогательные модули и артефакты модели создаются ячейками ноутбука при запуске.

Приложенный [requirements.txt](requirements.txt) отражает окружение учебного сервера. Некоторые зависимости ссылаются на его локальные пути через `file://`, поэтому установка через `pip install -r requirements.txt` на другой машине может завершиться ошибкой.
