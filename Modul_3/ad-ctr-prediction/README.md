# Прогнозирование CTR рекламы

Цель проекта — оценить вероятность клика для каждого рекламного показа. В учебной выборке 50 000 показов за 10 дней, доля кликов — около 17,2%.

[Открыть ноутбук с результатами](Model_for_predicting_CTR_for_an_advertisement.ipynb)

## Подход и результаты

В ноутбуке сравниваются логистическая регрессия, SVC и базовый DummyClassifier. Проверяются способы отбора признаков и влияние изотонической калибровки на качество вероятностей.

| Модель | PR-AUC | Log Loss | Оценка Бриера |
| --- | ---: | ---: | ---: |
| Логистическая регрессия | 0,384 | 0,404 | 0,1259 |
| Логистическая регрессия с изотонической калибровкой | 0,372 | 0,418 | 0,1265 |
| SVC с калибровкой | 0,317 | 0,4236 | 0,1317 |

На тестовой выборке из 10 000 показов лучшие результаты по этим трём метрикам получила логистическая регрессия без калибровки. Для демонстрации сохранения и повторной загрузки модели ноутбук использует логистическую регрессию с L1-регуляризацией (`C=100`) и изотонической калибровкой.

## Данные и окружение

Для повторного запуска нужен учебный датасет `/datasets/ds_s16_ad_click_dataset.csv`. Датасет не предоставляется. Таблицы, графики и метрики доступны в сохранённых выводах ноутбука.

[requirements.txt](requirements.txt) фиксирует окружение учебного сервера. Часть зависимостей ссылается на локальные пути через `file://`, поэтому установка через `pip install -r requirements.txt` на другой машине может завершиться ошибкой.
