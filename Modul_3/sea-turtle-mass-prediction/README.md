# Прогнозирование массы морских черепах

Цель проекта — предсказать массу морской черепахи по её измерениям и другим признакам. Целевые показатели на тестовой выборке — MAE менее 5 кг и R² не ниже 0,97.

[Открыть ноутбук с результатами](Model_for_predicting_the_mass_of_sea_turtles.ipynb)

## Подход и результаты

В ноутбуке сравниваются линейная регрессия, Ridge, Lasso и SGDRegressor при разных способах масштабирования признаков. В качестве базовой модели используется DummyRegressor.

Лучшей оказалась **Lasso на стандартизированных признаках**. На тестовой выборке модель показала **MAE 4,071 кг** и **R² 0,9712**, выполнив оба целевых условия. Наибольшие по абсолютной величине коэффициенты стандартизированной модели соответствуют размеру ласт и панциря.

## Данные и окружение

Для повторного запуска требуется учебный датасет `turtles.csv`. В ноутбуке используется путь учебного сервера `/datasets/turtles.csv`. Датасет не опубликован. Таблицы, графики и метрики доступны в сохранённых выводах ноутбука.

Основные библиотеки — pandas, NumPy, scikit-learn, Matplotlib, seaborn и PhiK.

Файл [requirements.txt](requirements.txt) фиксирует окружение учебного сервера. Часть зависимостей указана через ссылки `file://` на локальные пути сервера, поэтому на другой машине `pip install -r requirements.txt` может завершиться ошибкой.
